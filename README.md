# ग्रंथ प्रबंधन — iOS

Same app as the Android build, opened in a WebView shell.

Bundle id: `com.wnm.granthprabandhan`

GitHub Actions builds `Granth-Prabandhan-ios.ipa` on a Mac. That file is unsigned. An iPhone installs it only after you sign it with an Apple Developer certificate (Xcode or Sideloadly). Apple does not allow a Linux machine to sign an installable App Store IPA.
